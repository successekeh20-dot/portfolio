# Professional Portfolio Website

A responsive portfolio starter built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `professional_portfolio` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

## Personalize before publishing
- In `index.html`, replace `Your Name`, the intro, about text, project titles and service descriptions.
- Replace the portrait image URL with your own photo.
- Replace `hello@example.com` in BOTH `index.html` and `script.js` with your real email address.
- Replace the sample projects with screenshots, thumbnails, and links to your real work.
- Update the location and statistics to reflect your details.

## Features
- Five sections: Home, About Me, Work Done, Contract / Services, Message & Feedback.
- Left-side slide-out navigation opened by the menu icon.
- Dark/light mode toggle; preference is saved in local storage.
- Responsive desktop, tablet and mobile layout.
- Active navigation state while scrolling.
- Contact form validation and mailto handoff.

## Important: receiving messages
The form currently prepares an email in the visitor's email application. It does not store or send messages on a server. For direct submissions, connect a backend/API or a form service such as Formspree, Netlify Forms, or your own server endpoint.
